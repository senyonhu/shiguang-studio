旧塔的最后一盏灯 / 术式纪元 Ren'Py Demo 1.1.0

启动：解压完整文件夹，双击 TowerLastLight.exe。
不需要另外安装 Python、Ren'Py、Docker 或编译器。不要只复制 exe。
支持 Windows 10/11 x64；实际本机验收为 Windows 11 x64。

操作
- 点击 / 空格推进剧情；F11 切换全屏；F12 截图。
- 第 1 关只修改输出数字；第 2 关修改循环条件；第 3 关编辑循环片段。
- 第 3 关 Enter 换行，方向键移动，Backspace / Delete 删除。
- Ctrl+C 复制整个片段，Ctrl+V 或 Shift+Insert 粘贴，保留多行。
- 剪贴板被系统限制或占用时会提示重试，也可直接键入代码。
- 标准输入选择 0—6。最终“验证全部回路”用同一份代码测试 0、1、3、6。
- 保存进度后可从标题的“继续旅程”读取“快速存档”或“最近检查点”。
- Esc 打开任务菜单；演出可跳过；提示不扣分。

草稿 / 存档 / 记录
正常分发运行时保存到 %APPDATA%\RenPy\TowerLastLight-RenPy-1\。
草稿与记录位于其中的 learning 子目录。结算可导出 JSON。
恢复较新草稿会取消旧的通过标记，必须重新验证。
游戏目录可以移动，存档目录标识保持不变。

组件
Ren'Py 8.5.3.26051504 / 内置 Python 3.12.7
WASI SDK 22.0+m（官方 MinGW64 版）/ clang 18.1.2
Wasmtime 49.0.1
Clang 真实编译 C11 为 wasm32-wasip1，再由本地 Wasmtime 执行。
程序不启动 HTTP 服务，不使用账号、在线判题或首次运行下载。
缺失组件会报告故障，不会模拟成功。

美术
全部 13 张视觉图片均由内置 image_gen 生成功能制作。
背景、璃三表情、灯暗态/亮态/光晕、门、锁纹、UI 纹理为独立文件。
运行时由 Ren'Py 合成；没有将人物烘焙进背景。
音频为原有原创程序旋律的离线合成版，并非图片生成工具生成。
字体与运行依赖的许可证位于 licenses/。

边界
这是限定片段的教学 Demo，不是完整 IDE 或防作弊考试工具。
当前支持 i、n、int、for、while、if、else、break、continue、printf 等限定标识符。
不接受新增头文件、预处理指令、系统命令、外部文件 API 或任意完整 C 工程。
四组样例通过不等于证明所有输入均正确。
干净 Windows 10 电脑、物理断网首次启动、学校白名单及低配设备仍需部署方验收。
