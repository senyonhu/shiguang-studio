# 编辑器、展示器与制作 Skill 审计（0.1.1）

本次审计针对拾光 Studio 的人工编辑入口、同一后台上的 AI 制作、真实浏览器展示器和 Windows 便携交付。结论以本页的验收范围为准，不表示所有平台、媒体格式、外部 AI 宿主或商业素材服务都已验证。

0.1.0 及更早的审查记录保留在 `review/studio/`。其中的测试数量、源码指纹和部分功能状态属于历史记录；当前使用入口见 [使用说明](USER_GUIDE.zh-CN.md)，当前限制以本页和使用说明为准。

## 人能否从空白状态使用

默认编辑器包不附带工程、Demo 素材或首启示例。启动后显示欢迎页，用户可以新建作品、添加章节和场景、填写对白、导入自己的素材、配置选择与跳转、试玩、导出，再独立播放。创建第一句对白不需要预先导入素材或配置 AI。

面向人的流程使用名称、选择器和表单；后台工程 ID、配对与 AI 接入放在高级区域。修改事件或主题时保留未提交草稿，切换或试玩前给出处理入口。人工编辑与 AI 使用同一工程、修订和事务机制。

这次检查覆盖了全部 11 种事件表单和一次从空白作品到独立导出的实际 UI 操作。尚未组织新用户可用性研究，因此这里的“可用”指已验证的操作闭环，不代表无需学习即可掌握所有制作能力。

## 修复的主要问题

| 场景 | 修复前的影响 | 0.1.1 的处理 |
| --- | --- | --- |
| 首次连接和切换工程 | 连接徽章先出现，后续初始化可能清空输入或吞掉配置操作 | 初始化期间保持完整加载状态，完成读取后开放编辑 |
| 事件或主题有草稿 | 切换、试玩或后台更新可能使人工输入丢失 | 草稿守卫覆盖关联入口；取消后重新读取最新工程 |
| 提交后网络结果不明 | 再次提交可能使用新请求 ID，把同一动作执行两次 | 同一待确认提交复用请求 ID 与基础修订 |
| SSE 初始订阅和重连 | 连接窗口内的后台修改可能未显示 | 订阅 ready 后补读，仍保护未提交草稿 |
| 空名称输入回退 | DOM 看起来已修改，但后台仍是旧值 | 将实际输入恢复为已保存值，并提示校验失败 |
| 删除场景后撤销 | 场景可能追加到末尾，改变章节内顺序 | 撤销记录并恢复原位置 |
| 试玩期间继续编辑 | 内容快照与后来修改的关卡程序混用 | 试玩票据固定素材和关卡文件；后续试玩读取新修订 |
| 连续交互关卡 | 一次完成消息被重复推进，跳过下一关卡 | 完成只回执一次，进入新关卡清空旧快照与消息去重状态 |
| ready 不带序号的关卡 | 自动生成的 ready 序号吞掉第一条 checkpoint | 无编号 ready 不消耗进度序号，显式编号仍校验 |
| 长等待、手动推进和自动播放 | 等待超过四秒提前完成；旧定时器跳过下一句 | 使用真实经过时间，读档保留剩余等待，清理过期定时器 |
| 音频生命周期 | 停止、循环、音量、淡出或重新开始未完整生效 | 按声道处理动作，清理旧宿主与定时器，恢复背景音 |
| 视频参数 | 不可跳过、结束或错误策略未实际执行 | 按事件参数推进，错误重播最多一次 |
| 存读档 | 不同作品覆盖槽位，历史重复，结局和等待丢失 | 按工程隔离三槽位，校验工程与修订，保存当前停止状态并深拷贝快照 |
| 空槽或损坏存档 | 读取失败仍清空当前剧情 | 错误提示保留当前进度；循环错误提供返回标题入口 |
| 跨场景事件跳转 | 合法的目标事件在运行时找不到 | 全局定位目标事件，同时校验指定场景与事件的一致性 |
| HTML 关卡权限 | 同源 iframe 可读取宿主 DOM 和玩家存档 | 只允许脚本的隔离 iframe，使用 CSP 和有范围限制的 fetch 桥接 |
| 旧式关卡来源检查 | 隔离页面的加载方式使旧关卡无法发送 ready | 用隔离 Blob 页面保留 URL 来源语义；安全来源仍不透明，原正式 C 关卡无需重装 |
| 未声明编码的关卡 | 转为 Blob 后中文可能乱码 | 明确 UTF-8 MIME 和字符集声明，并覆盖无 meta 的旧关卡 |
| 导出附带的简易服务器 | 可能访问运行数据，路径异常处理不足 | 只开放播放器与作品资源，拒绝隐藏路径、符号链接和越界访问，支持媒体 Range |
| 包内遗留静态托管脚本 | 同名前缀目录、符号链接和坏 URI 的校验不完整 | 使用真实路径与分段检查，仅允许 GET/HEAD，坏 URI 返回 400 |
| Skill 制作入口 | 空工程、错误工作区或当前关卡信息不明时仍可能开始写入 | 明确工作区、工程和关卡，先做只读预检；修改通过后台事务和工具执行 |

人工编辑器和展示器浏览器回归共 38 项。完整的 C Demo 验收还修正了关联 Skill 检查脚本的旧存档键、过宽按钮计数和过期校验文案。正式作者工程 32 个内容文件以及原展示器 33 个内容文件均保持不变；仅程序与制作资源更新。

重点新增浏览器反例包括：连续关卡不跳过、快照不跨关卡传播、checkpoint 序号 1 保存与恢复、真实长等待、音频停止与重启、结局读档、跨工程存档隔离、不可跳过视频、跨场景事件目标、HTML 关卡隔离、受控本地 C 服务访问、旧式 Origin 握手、无编码声明的中文关卡、缺失/不发送 ready 的关卡退出，以及损坏存档保留当前进度。

编辑器反例覆盖空白入口、主题与事件草稿、后台修改同步、名称回退和撤销顺序。后台测试使用隔离工作区；便携验收针对最终 ZIP 实际解压，清单逐文件校验 SHA256，在中文和空格路径、没有全局 Node 的 PATH 中运行 CMD 入口。

正式 Demo 作者内容不用于破坏性测试。更新现有服务时，仅替换程序文件，校验作者内容散列保持一致。公开仓库与 Release 不包含作者工作区、会话、配对密钥或本机生成任务。

## 保留的限制

- Windows 10/11 x64 是便携交付目标；本轮实测为 Windows 上的 Edge。其他操作系统和浏览器未承诺同等验收。
- 外部 AI 宿主实际加载插件清单和 Skill 尚未验证。MCP stdio 协议、工具、同一后台工程和静态插件检查已覆盖；`KI-001`、`KI-022` 保留。
- 图片与视频生成只有明确标记的测试适配器。没有接通真实商业服务，也未验证其费用、限流或服务异常行为。
- 人物位置和进出场可以使用，但人物事件的 `durationMs` 尚未实现完整补间动画。快进、统一音量设置、字号设置也不属于本版已完成能力。
- 分支通过选择与明确跳转配置。通用变量条件分支和可视化节点连线编辑尚未提供。
- HTML 关卡需要自包含内容、经典脚本或允许范围内的资源；隔离环境不承诺任意第三方网页、外部 module 导入、无限制网络请求或访问宿主页面。
- C 执行器是独立服务，需要另行启动并在关卡初始化配置中明确地址。它不包含在默认空白编辑器/展示器 ZIP 中。
- 玩家存档位于浏览器本地存储，按作品和浏览器来源隔离，没有文件导入导出。没有工程绑定信息的旧存档不会自动迁入，以免误读其他作品；旧键不被删除。改变服务端口、浏览器配置或清理浏览器数据可能使旧槽位不可见。
- 后台预览会话和临时试玩链接不能跨后台重启继续使用。保存作者工程后重新发起试玩即可。
- 没有代码签名、自动更新器或全量性能承诺；大型素材库与极限规模测试的历史结果不作为本次复测结论。

## 复现命令

在仓库根目录、安装依赖并完成构建后执行：

```powershell
npm test
npm run typecheck
npm run studio:plugin:check
# 单独终端先运行 npm run dev，以下 UI 测试连接 127.0.0.1:5173
npx playwright test tests/e2e/studio-live.spec.ts tests/e2e/studio-human.spec.ts tests/e2e/studio-audit.spec.ts
npx playwright test tests/e2e/p2-player.spec.ts tests/e2e/player-audit.spec.ts
# 输入目录需包含当前版本默认空白编辑器和展示器两个 ZIP
node scripts/studio-portable-check.mjs --release-dir release/audit-v0.1.1-2026-10-01 --out artifacts/portable-recheck
```

`artifacts/`、`release/`、作者工作区与运行数据被 Git 忽略。用户在本机运行上述命令会得到新的验收输出；历史输出不会作为源代码提交。
