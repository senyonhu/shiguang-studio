# 公开发布范围

本次发布把拾光 Studio 主版本切换为 Codex + RenPyBridge 的 Windows 同窗 HTML 方案。旧 `v0.1.1` 标签、发行资产和 Git 历史保留；主分支更新使用正常后继提交，不重写旧历史。

版本固定为核心/插件 0.1.3、剧情 schema 1.0/1.1、原生同窗宿主 0.2.0、RenPy SDK 8.5.3.26051504、WebView2 固定版 154.0.4258.53 x64。.NET SDK 10.0.401 和 WebView2 NuGet 1.0.4258.31 由宿主构建脚本锁定。固定浏览器公开下载锁见 `metadata/webview2-runtime.lock.json`；安装前仍执行本机签名与文件完整性检查。

发行资产包含公开源码 ZIP、独立 HTML 演示游戏 ZIP、公开验证摘要和 SHA256 清单。源码 ZIP 按白名单制作，仅包含源码、测试、插件、生产示例、必要工具和公开文档；原生/浏览器二进制只在完整游戏发行包内。源码 ZIP 与 Git 提交保留文件原始字节，避免换行转换破坏小游戏内容摘要和原生源码绑定。

私人作品、用户存档、WebView2 profile、浏览器 Cookies、账号配置、凭据、历史失败日志和个人资料目录路径不属于公开资产。原始验收记录留在本机，公开摘要只报告版本、结果、摘要和适用范围。游戏包中的原生构建回执可以保留开发源码目录的技术来源路径；它不包含个人浏览器资料或账号凭据。

准备依赖、构建宿主、安装插件、SDK 验证、真实游戏验收是不同门槛。具体结果和未完成环境检查见 [VALIDATION](VALIDATION.md)。该版本作为预览版发布，适合在当前已验证范围内体验和制作；跨环境正式支持需要继续补齐物理验收。

没有为整个核心新增统一许可证。保留示例和第三方自身的许可文件，不从旧仓库或公开状态推断 MIT 授权。自包含宿主构建工具将固定 .NET 运行时和 WebView2 SDK 归档中的五份原始许可/声明纳入文件清单和发行包，并验证对应归档摘要。
