2026-10-03 最终审查修复了三类实际问题：插件升级会误判合法 SDK 编译缓存并替换已有 SDK；旧宿主的后台线程、WebSocket 和 WebRTC 可以绕过最初的网络请求拦截；剧情窗口客户区短暂变为零时，运行时会终止小游戏。失败复现和原始日志保留在本机，不把旧结果作为修复后通过的证据。
