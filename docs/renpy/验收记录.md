## 已记录的引擎适配

Ren'Py 8.5.3 原生 Input 的粘贴处理会去除换行，已用 `CodeEditor` 修正。输入仍是轻量片段编辑，没有鼠标选区或完整 IDE 能力，Ctrl+C 复制整个片段。源码使用关闭连字的 JetBrains Mono，避免把 `<=` 显示为单字符数学符号。

Ren'Py 8.5.3 测试模拟器的等号映射误写成冒号，并缺少大括号映射；仅在开发测试脚本中校正。模拟器对 Ctrl+V 额外注入 `v`，因此剪贴板自动化使用同一粘贴动作绑定的 Shift+Insert。游戏本身沿用真实 SDL 输入，不修改 SDK。

先前系统剪贴板粘贴实测曾通过；最终复验 Windows `OpenClipboard(NULL)` 返回错误 5（拒绝访问），SDK 与发行包均受影响。游戏已对复制/粘贴的系统错误显示提示。最后一次恢复测试只在系统拒绝访问时注入剪贴板字节，日志明确包含 `CLIPBOARD FIXTURE`，不把这次结果称为 OS 剪贴板集成验证；正常桌面环境需再验复制/粘贴。

正式 ZIP 包内的 Clang/Wasmtime 已做 8 项实测；使用包内 Python 与 Ren'Py 引擎完成 9 项通关断言和 6 项读档/粘贴断言。路径包含中文与空格，测试成功后移除注入的测试脚本。

## 尚未验证

- 干净 Windows 10/11 电脑的首次物理断网运行。现有本机测试只依赖随包路径，游戏无网络请求和下载流程，但不把它等同于干净设备断网验收。
- 学校应用白名单、最低配置机器、不同 DPI 和多显示器布局。
- 拔电等突然断电、磁盘满、长期运行压力和任意恶意编译器输入；代码中已做有界输出、超时、原子备份及写入错误提示。
- 3—5 名学生的实际体验、目标 15—20 分钟时长和理解迁移访谈。

本地结果可被用户修改，不作为防作弊考试成绩；四组样例通过不等于证明所有输入都正确。
