# 拾光 Studio 可交互演示

本版用于体验和选择产品方向，并非完整发行引擎。原 Demo 保持独立入口。

## 打开

在项目目录双击 **启动剧情工作台.cmd**，或打开运行中的 http://127.0.0.1:5190/studio.html 。本机依赖已就绪，无需启动 Docker、Python 或评测服务。启动器使用构建后的文件；后续改源码须先运行 `npm run build`。

## 三分钟体验

1. 右侧改一句台词，预览立即更新，修改自动保存在本浏览器。
2. 打开“AI 变更审查”，试着采用、撤回、保留修改。先手改原文或锁定段落后，示例不会覆盖它。
3. 点击“试玩故事”，体验两个分支之一；进入星图关卡，把三个金色指针对齐顶端引路星；完成后返回剧情。
4. 关卡中途刷新，回到工作台点击“继续上次试玩”，再进入关卡，可以恢复刚才的星环角度。改过工程后，旧试玩存档会提示重新开始。
5. 在素材库导入自己的背景图片，在右侧更换人物显示；导出配置后可再次导入。

## 本版边界

- 真实可操作：图片与透明立绘、台词、剧情分支、HTML 关卡、参数与结果通信、关卡进度、工程结构校验、配置导入导出、本机保存、审查/冲突/锁定。
- AI 审查使用两条预置修改示例，没有在线调用模型，不接受任意自然语言生成。
- 本版是无声美术预览；尚未接入音乐、配音或视频。
- 引擎由配置驱动，但体验版只内置星图一种关卡；当前不支持直接导入任意 HTML 插件。
- 导出的是 JSON 配置，内置素材使用本项目路径；用户导入的小图片包含在配置内。它不是独立发行包。
- 工程与试玩进度存在浏览器本地，清理站点数据会丢失。开发入口 5173 和发行预览 5190 使用不同站点存储；可用导入导出迁移工程。
- 素材是本次使用内置图像生成工具制作的样板，提示词见 `studio-art-prompts.md`。

## 检查

`npm run build` 编译全部入口。`npm test` 检查配置与现有协议。`npx playwright test tests/e2e/studio.spec.ts --reporter=list` 在已运行的开发预览 5173 上验证真实操作。浏览器验证覆盖手改保存、导出下载、AI 采用/撤回/锁定、无效导入保护、分支、关卡保存恢复和完整通关。
