- Docker Desktop 4.60.1 在本机存在退出后残留临时 Unix socket 的重解析点故障；已提供只处理该特定情况的备份式恢复脚本，详见 README。它是宿主应用问题，不是假编译或降级为源代码匹配。
- 新版 Isolate 2.7 已在容器内编译并实测；未关闭 cgroup，修复了 cgroup v2、配置锁目录、旧计时参数和服务用户的兼容问题。
- Monaco 独立按需加载的 JS 块较大，构建有体积提示；首次进入编辑器会有加载开销。构建未报错误。
- 15—20 分钟是设计目标，未进行教师/学生真人可用性测试。自动化通关不代表零基础学生已经掌握循环。
- 使用原创矢量场景、角色和程序音频；尚未制作配音或商业级手绘资源。
